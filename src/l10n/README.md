# Country name data

The bundled `territories_de.json`, `territories_nl.json`, and
`territories_ru.json` files are unmodified territory-name datasets from
Unicode CLDR JSON:

- Repository: `unicode-org/cldr-json`
- Commit: `a79b499916d486dca4b0f74fe423ea457705fdd9`
- Paths: `cldr-json/cldr-localenames-full/main/{de,nl,ru}/territories.json`
- Retrieved: 2026-07-25
- License: Unicode License v3 (`Unicode-3.0`)

Copyright © Unicode, Inc. The complete Unicode License v3 copyright and
permission notice is bundled in `LICENSE-UNICODE`; the canonical copy is
available at <https://www.unicode.org/license.txt>.

BearWave reads only exact two-letter territory codes. CLDR macroregions and
alternative-name entries remain bundled unchanged but are not used.
